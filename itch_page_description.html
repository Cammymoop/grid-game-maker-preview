Grid Game Maker is a free tool for easily turning your grid-based ideas into games quickly and with pretty visuals. Try it in the browser or download for Windows/Mac/Linux below. You can play any of the 3 full example games or edit them, create new levels, create your own games from scratch, or import games created by other people to play or play around with.

Why "Preview"?

This is the Preview version which is basically the "1.0" version, it is fully featured and already usable but there are many things that I want to improve, add, or rework. This version is open source and will be somewhat supported for quite a while but my focus will be primarily on a full rewrite forthe next version of GGM using everything I've learned from the process of creating this first version and from feedback and seeing what people do with it.

Playing games, importing games, custom levels & level packs

Grid Game Maker Preview comes with 3 complete example games. On the main menu select the game title option and press left or right to choose between installed games, press menu confirm on the title option or click the menu icon to open a menu with all installed games to pick from a list.

To play a .zip game use the "Create or Import" button from the main menu and select or upload the game's zip file, no need to unzip it.

Custom levels for an existing game can be imported from a .json file, which can contain a single level or a pack of levels. First Select the game which the levels were made for at the main menu, then import levels from the main menu or from the "Import Levels" button in the level select menu.

How do I edit or create games or levels?

Here's a video quick start guide which shows how to use GGM to create or modify games or make custom levels, and the text version based on that video.

Games may be a "release version" which is a specific, unmodified version of a game. On the main menu, release versions show a white title with no orange border. Custom levels can be created for release versions, but to modify the game, graphics, or builtin levels or lists you need to unlock the game by creating an "edited version" which is a copy of the release version. Clicking "Edit Game" from the main menu will open a dialog that gives you a couple options on how to do this. When modifying an existing game it is recommended to set a default identifier in your profile settings which is used like a prefix for the game ID so that original and modified versions are identifiable and show up as separate choices in the main menu.

Only one version of a particular game id (including prefix) is loaded at a time. Different installed versions can be switched between on the main menu if the version switcher is enabled in your profile options. Every installed release version of a game is kept by default, and GGM may create and keep backup copies of edited versions such as when importing over the current edited version.

Important Note For Editing With the Web Version

If editing games or levels in the web version, please make sure to export the game or custom levels frequently and backup those copies appropriately. Browser storage (IndexedDB) is used to save games, levels, profiles and save files, in practice this may be kept by your browser for an indefinite amount of time, but it should not be considered a reliable place to permanently keep your games. It is entirely up to the browser how and when to keep or get rid of this data, and it is also easily possible to accidentally clear this data.
